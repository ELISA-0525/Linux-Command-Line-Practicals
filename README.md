## Project Overview

This repository contains practical coursework completed for the Operating Systems module.

The coursework focuses on fundamental Linux operating system concepts and command-line operations. The activities were performed in a Linux environment using UTM virtualization on macOS.

The report documents practical exercises with screenshots of terminal commands and their corresponding outputs.

## Objectives

- Develop familiarity with the Linux command-line interface.
- Practice navigating the Linux file system.
- Explore file and directory manipulation.
- Understand Linux file permissions.
- Gain practical exposure to shell scripting.
- Practice searching for and viewing files through the terminal.
